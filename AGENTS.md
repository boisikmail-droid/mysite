# Мой сайт-портфолио

Это статическое русскоязычное портфолио Виктора Мельникова. Интерфейс имитирует рабочий стол с приложениями. Проект использует HTML, CSS и JavaScript и открывается без установки зависимостей или сборки.

## Где что находится

- `index.html` — входная страница GitHub Pages. Перенаправляет на `i-desktop.html`.
- `i-desktop.html` — рабочий стол, окна приложений, контакты и сведения об опыте.
- `integrations.html` — интерактивная карта, которую рабочий стол открывает в окне «Интеграции» через `iframe`.
- `integration-checklist.html` — вспомогательная страница для выбора интеграций для резюме.
- `project-integrations.js` — каталог интеграций и роли в проектах. `data.js` — общие данные сайта.
- `desktop-assets/` — изображения, иконки и звуки рабочего стола. `integration-icons/` — иконки сервисов.

## Запуск и проверка

- Откройте `index.html` в браузере локально. Для проверки по HTTP запустите `python -m http.server 8000` из корня репозитория и откройте `http://localhost:8000/`.
- GitHub Pages публикует проект по пути `/mysite/`. Используйте относительные пути к страницам, скриптам и ресурсам.
- При изменении интерфейса проверьте рабочий стол и окно интеграций на широком и узком экранах. При изменении каталога проверьте также страницу выбора интеграций.
